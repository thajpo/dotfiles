Create an executable contract for: $@

Inspect first. Resolve discoverable facts; stop for human approval at consequential choices. Keep it narrow and implementation-ready. Include task ID, base commit, goal, user-visible behavior, decisions and rationale, interfaces/types/schema, compatibility and error semantics, allowed paths, non-goals, acceptance commands with expected results, escalation triggers, and tests/skeletons to create before handoff. Prefer YAML plus only essential explanatory notes. Do not implement until approved.

This contract scales to consequential BUILD/MAJOR work. For FAST/RIP tasks a full contract is not required — a lightweight scope note suffices.
