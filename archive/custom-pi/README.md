# Retired Custom Pi System

This directory preserves the controller-driven Pi implementation retired on
2026-08-15. It is archived source and historical documentation, not an active
dotfiles component.

The original relative layout is retained under this directory. Runtime state,
provider credentials, installed generations, and controller-owned worktrees are
not committed here. They were preserved separately in the local retirement
archive before the custom runtime was removed.

The active `pi` command now delegates to oh-my-pi (`omp`). Do not restore these
launchers or integrations piecemeal; any future revival should begin with an
explicit architecture and migration review.
